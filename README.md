# SPHEREx Megaconstellation Contamination — Extended Analysis

Code for the real-orbital-data extension of the undergraduate project
*"Investigation of Celestial Events and Megaconstellation Effects on Telescopes"*
(SRM Institute of Science and Technology, April 2026).

This extension is independent of the original reflectance-based model: it uses
real, live TLEs (SGP4), a Monte Carlo statistical encounter model, direct
propagation of real currently-orbiting satellites for validation, blackbody
thermal-IR photometry, and a TLE positional-uncertainty error budget.

See `SPHEREx_combined_manuscript.docx` (in the repo root) for the full write-up,
including what was validated, what wasn't, and an openly-reported discrepancy
with the published literature value for a full-constellation-build-out scenario
that was investigated but not resolved.

## Contents

```
scripts/
  01_full_window_propagation.py              Real SGP4 propagation of SPHEREx + a real
                                              OneWeb satellite across one full exposure
                                              window (112.5s), TEME frame, boresight +
                                              phase-angle geometry.
  02_monte_carlo_idealized_shells.py         First-pass statistical Monte Carlo: 8
                                              idealized circular-orbit megaconstellation
                                              shells, ~2.1M synthetic configurations.
  03_monte_carlo_eclipse_brightness_filters.py  Same model + eclipse filtering + a real
                                              photometric detection-threshold cut.
  04_real_catalog_validation_starlink.py     Direct, non-statistical validation: 6 real
                                              Starlink satellites propagated against
                                              SPHEREx's real orbit over 30 real days.
  05_real_catalog_validation_oneweb.py       Same, for one real OneWeb satellite.
  06_real_events_and_blackbody_photometry.py Extracts every real FOV-crossing event and
                                              computes blackbody thermal-IR flux across
                                              SPHEREx's 102 spectral bands for each.
  07_tle_uncertainty_error_budget.py         Monte Carlo TLE positional-uncertainty
                                              propagation (1 km epoch + 2 km/day growth)
                                              into range/phase-angle/brightness for every
                                              real crossing event.

figures/
  fig1-5_*.png                               Figures generated by scripts 01-07.
  original_fig5.1_*.png, original_fig5.2_*.png  The two original reflectance-model
                                              figures from the April 2026 thesis.

report_generation/
  build_extension_report.js                  docx-js script: generates the standalone
                                              extension report.
  build_combined_manuscript.js                docx-js script: generates the full combined
                                              manuscript (original thesis content, cleaned,
                                              + the extension).

SPHEREx_combined_manuscript.docx              The combined manuscript (generated output).
```

## Requirements

- Python 3.10+, packages: `sgp4`, `numpy`, `matplotlib`, `scipy`
- Node.js with the `docx` npm package, for `report_generation/`

```bash
pip install sgp4 numpy matplotlib scipy
npm install docx
```

## Running

Scripts are numbered in the order they were actually run and depend on each
other's `.pkl`/`.npz` outputs (each script prints what it writes). Run in
order from `scripts/`:

```bash
python 01_full_window_propagation.py
python 02_monte_carlo_idealized_shells.py
python 03_monte_carlo_eclipse_brightness_filters.py
python 04_real_catalog_validation_starlink.py
python 05_real_catalog_validation_oneweb.py
python 06_real_events_and_blackbody_photometry.py
python 07_tle_uncertainty_error_budget.py
```

## Data provenance

All satellite orbital elements (TLEs) are real, live two-line elements
retrieved from Celestrak in September 2026. NORAD IDs and TLE epochs are
recorded inline in each script (SPHEREx: 63182; Starlink: 48294, 48375,
48646, 47650, 47796, 44768; OneWeb: 55158). TLEs go stale — re-fetch current
elements before re-running for a different date.

## Known open issue

The idealized statistical model (script 02) over-predicts the published
full-build-out contamination rate (Borlaff et al. 2025, Nature) by roughly
11x. Three candidate causes were tested and ruled out (see script 03's
eclipse/brightness filtering, and the manuscript's §7.3). This is reported
as an open limitation, not silently corrected — see the manuscript for the
full investigation.
